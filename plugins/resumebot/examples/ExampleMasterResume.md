# Example Master Resume — Fictional Persona

> **This is a worked example using an entirely fictional person.** It shows the structure a
> master resume should take: a header note with standing rules, a single career spine,
> a selected-achievements band, grouped competencies, and per-role bullets rich enough
> to cut tailored variants from. Replace every word of it with your own history.

---

> **Master document, not for submission.** Tailored versions are cut from this.
> Standing rules for every cut: no graduation years, no age signals, no client names,
> delivered work only, no manufactured metrics.

## Master-resume conventions this example demonstrates

1. **One spine, many cuts.** The master holds everything true; variants subtract,
   never invent.
2. **Header rules travel with the document** so every future edit session sees them.
3. **Achievements band up top** — the five facts a skimming recruiter must see.
4. **Competencies grouped by theme**, a few terms each, for ATS keyword alignment
   without keyword stuffing.
5. **Bullets are evidence, not adjectives** — each names a real delivered thing, with
   metrics only where the number itself is the story.
6. **No certifications section unless certifications are actually held.**
