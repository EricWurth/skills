# Example Match Profile — Fictional Persona

> **Worked example for the same fictional person as ExampleMasterResume.md.**
> This is the file the career-coach session produces. Every scan, score, and
> scheduled task reads from it — it is the single source of truth for what
> counts as a good job. Replace all values with the user's own answers.

## Search strategy

Search BROAD function keywords and let fit float to the top — never
title+level combos, never pre-filtered by seniority. Terms for this persona:
**distribution operations, supply chain operations, warehouse operations,
implementation manager, program manager (operations), continuous improvement**.
Automation/WMS adjacency is an additive bonus on any of these, never a
requirement.

## Hard gates — fail any one = reject

1. **Staleness:** under 42 days = normal; 42–89 days = watch tier; 90+ days
   with no republish = presumed dead. Verify the posting date on the real ATS
   page, not the job board's unreliable "posted" label.
2. **Fit minimum:** could this person do the job at all, even as a stretch?
   Only reject on a quantified years-of-specific-experience requirement that
   IS the role's core mandate.
3. **Location:** remote (no state restriction excluding Ohio) or within
   commuting distance of Columbus, OH. One relocation exception: Chicago
   metro, where family ties and comp justify a move. Anything else on-site =
   reject.
4. **Comp minimum:** any real chance the role clears **$110K** base.

## Bonuses (additive priority, never requirements)

- **Level:** Senior Manager / Director = bonus. IC roles stay in scope;
  judge seniority by years-required, not title words.
- **Comp bonus:** disclosed range floor clears $135K.
- **Comp win:** range clears $170K.
- **Industry:** food/grocery and healthcare distribution score extra
  (regulated, sticky, matches the evidence base).

## Exclusions and routing

- **Excluded employers:** MegaFreight Corp (fictional former employer —
  bad exit, do not reapply), and any staffing-agency posting that hides
  the real employer.
- **Aggregator-routed postings:** never auto-apply through an aggregator;
  find the real employer's career page, note the aggregator in the tracker.
- **Same-company dedupe:** multiple active postings from one employer →
  keep the single best fit, mark the rest rejected citing dedupe.

## Fit scale (persona-tuned)

Defaults from the job-scan skill apply; this persona sharpens 5 and 4:

- **5:** WMS/distribution operations leadership with multi-site scope — the
  exact evidence base. Custom resume + letter if the portal takes one.
- **4:** operations or implementation leadership where one named gap exists
  (e.g., industry mismatch, no direct WMS platform named). Tailored variant.
- **3 and below:** per the standard scale; generic variant, minimal work.

## Location priority (sequencing, not fit)

Remote and Columbus-metro = high priority, worked first. Chicago-relocation =
medium ("good but slower — hiring plus a move"). This orders the queue; it
NEVER changes a fit score or effort tier. To park the whole relocation tier
for a while, set those rows to `deferred` — parked, not rejected.

## Philosophy

Wide net while between roles. Only the four hard gates justify dropping a
role — never frame a partial fit as a "pass"; log the gaps as tailoring
info and rank by effort-to-apply.
