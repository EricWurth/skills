# Content Rules

Checklist applied to every resume, cover letter, and document in your name. The
build-packets lint gate enforces the mechanical ones; the resume-writer agent
applies all of them. Edit this file to fit your situation — it is YOUR policy.

## Shipped defaults (keep unless you have a reason not to)

1. **Delivered work only.** Never "designed/built/established" for anything that
   didn't ship. Unexecuted proposals are not resume material, even caveated.
2. **No manufactured KPIs.** Keep only metrics with real signal (money, team size,
   time saved); drop filler percentages.
3. **No certifications unless actually held.** Never list "candidate" or "in
   progress" status. If you register or pass one, update this line.
4. **No AI tells.** No em dashes, no mid-sentence inline bolding, no formulaic
   bold-lead-in bullets. Structural bolding (name, headers, dates) is fine.
5. **No age signals.** No graduation years, no "N+ years" phrasing that dates you.
6. **Gaps: silence by default.** Never preemptively address a missing
   qualification. Only exception: an explicit "required" qualification the reviewer
   will certainly notice gets exactly one confident sentence.
7. **Salary questions:** answer "flexible depending on the total benefits package"
   unless a number is mandatory; your number strategy lives in form-answers.md.

## Fill in for yourself

- **Confidentiality:** may former clients/customers be named? If not, list the
  forbidden names here (the lint gate reads this list) and the sector+scale
  descriptions to use instead:
  - `<name>` → "`<sector + scale description>`"
- **Sensitive framings:** claims that need specific wording (a disputed metric, a
  layoff, a short tenure) — write the approved framing here so every document uses
  the same one.
- **Omissions:** anything true you've decided to leave off (an old career track, a
  degree, a role) — record the decision so no variant accidentally restores it.
