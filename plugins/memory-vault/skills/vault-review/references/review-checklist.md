# Review Checklist (condensed, for repeat runs)

1. Gather: episodes since last review, Candidates first; Claude Code auto-memory dirs (unverified); intentions queue.
2. Cluster: 2+ contexts = evidence, 1 = anecdote. Draft proposals with routing, honest provenance, cited evidence.
3. Staleness: last_reviewed > 4 weeks or contradicted → confirm or supersede. Never delete.
4. Reflections: max 2-3, type: reflection, provenance: hypothesis, multi-episode sources.
5. Approval: present everything item by item. Nothing applies without an explicit yes.
6. Apply: write files per schema; close validity windows; INDEX under 200 lines; regenerate CATALOG fully; validate frontmatter; check sync conflicts; update intentions; write the review episode.
7. Report: scorecard + next review date. Flag empty Candidates as a capture failure.

Invariants that survive any shortcut: append-only episodes, supersede-not-delete, human approval per item, hard budgets, provenance honesty (suggestion ≠ decision).
